# ไฟล์สำหรับ Workshop

[กลับไปหน้า Workshop](../readme.md)

ไฟล์ทั้งหมดเป็นข้อมูลสมมติสำหรับฝึก ไม่ใช่ข้อมูลจริงของลูกค้าหรือแคมเปญ ดาวน์โหลดเก็บไว้ในเครื่อง แล้วเลือกแนบไฟล์จากเครื่องระหว่างทำ exercise ได้เลย

| กิจกรรม | ดาวน์โหลด | ถ้าแนบไฟล์ไม่ได้ |
|---|---|---|
| Promotion Review | [Excel](copilot-in-action/modern_trade_promotion_review.xlsx) | [ข้อความ 6 แถว](pasteable/promotion-excerpt.md) |
| Launch Readiness | [ZIP](copilot-in-action/new_product_launch_readiness.zip) | [Brief และ tracker 4 workstreams](pasteable/launch-excerpt.md) |
| Customer Feedback — ฝึกต่อ | [ZIP](copilot-in-action/customer_feedback_issue_response.zip) | [Feedback 4 รายการและ guideline](pasteable/feedback-excerpt.md) |

## ไฟล์แยกจาก ZIP

- Launch Readiness: [Tracker](copilot-in-action/launch_readiness_tracker.xlsx) · [Brief](copilot-in-action/product_launch_brief.docx)
- Customer Feedback: [Log](copilot-in-action/customer_feedback_log.xlsx) · [Guideline](copilot-in-action/issue_response_guideline.docx)

แตกไฟล์ ZIP ก่อนแนบไฟล์ `.xlsx` หรือ `.docx` ไม่ต้องอัพโหลด ZIP เข้า Copilot

> ข้อความสำรองเป็นข้อมูลบางส่วน ให้ตรวจยอดและจำนวนจากชุดที่เราใช้เท่านั้น ผลอาจต่างจากไฟล์เต็ม ส่วน 6 งาน Sales และงานสื่อสารมีข้อมูลสั้น ๆ ใน Prompt อยู่แล้ว ไม่ต้องดาวน์โหลดไฟล์

> หาก Chat ใช้ไม่ได้ ให้เก็บ Prompt และลองตรวจตัวอย่างกับผู้สอนก่อน การดูตัวอย่างยังไม่ถือว่าทดลองสำเร็จด้วยบัญชีของเรา
