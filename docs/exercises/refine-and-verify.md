# Exercise: ตรวจและปรับผลลัพธ์ก่อนใช้งาน

<PageIllustration id="verify" />

[กลับไปหน้า Workshop](../index.md)

## Exercise Overview

เราจะนำผลงานที่ทำมาแล้วกลับมาตรวจหลักฐาน แล้วปรับข้อความให้เหมาะกับผู้รับ เหมือนตรวจใบเสร็จก่อนสรุปค่าใช้จ่าย—คำตอบดูดีแล้วก็ยังต้องเทียบกับต้นทางนะครับ

> **License:** เส้นทางหลักใช้ Copilot Chat แบบ Basic กับข้อมูลที่เราให้เอง ไม่ต้องเพิ่ม Microsoft 365 Copilot add-on license แต่การเข้าถึง Chat และการแนบไฟล์ในบัญชีผู้เรียน **ต้องตรวจสอบก่อนเริ่มอบรม**

## Prerequisites

1. เปิด Chat จาก [Promotion Review](copilot-in-action/modern-trade-promotion-review.md) หรือ [Launch Readiness](copilot-in-action/new-product-launch-readiness.md)
2. เลือกผลลัพธ์ 1 ชุดจากงานนั้น พร้อมไฟล์ต้นทางหรือข้อความตัวอย่างชุดเดิม ใช้ผลลัพธ์ชุดนี้ต่อทั้ง Practice 1 และ 2

**ฝึกในคลาส:** Practice 1–2

<span id="practice-1"></span>

## Practice 1: เทียบคำตอบกับหลักฐาน {#practice-1-เทียบคําตอบกับหลักฐาน-10-นาที}

<PracticeIllustration id="verify-01" />

เราจะตรวจข้อสรุปสำคัญกับต้นทางเพื่อแยกสิ่งที่ยืนยันได้ออกจากสิ่งที่ยังต้องถามต่อ

#### Steps

1. เลือกผลลัพธ์ 1 ชุดที่มีตัวเลขหรือสถานะงาน เปิดต้นทางที่ใช้ใน Chat นี้ควบคู่กัน
2. ถ้าใช้ข้อความตัวอย่างแทนไฟล์ ให้ตรวจเฉพาะขอบเขตข้อความชุดนั้น ไม่เทียบผลรวมกับ workbook เต็ม
3. ส่ง prompt ด้านล่างใน Chat เดิม

   ```text
   ตรวจคำตอบล่าสุดกับข้อมูลต้นทางที่ฉันให้ไว้ใน Chat นี้
   เลือกข้อสรุปสำคัญไม่เกิน 3 รายการ แล้วจัดเป็นตาราง:
   ข้อสรุป | ข้อมูลต้นทางที่ใช้ | ผลตรวจ | สิ่งที่ต้องแก้หรือถามต่อ

   ตรวจตัวเลข สถานะงาน และข้อสรุปเชิงสาเหตุ
   แยก Fact | Interpretation | Information needed ให้ชัดเจน
   ระบุชื่อ sheet และแถว หรือหัวข้อข้อความต้นทางเมื่อหาได้จริง
   ถ้าหาหลักฐานไม่พบ ให้ระบุว่า "ยังยืนยันไม่ได้" ไม่สร้างแหล่งอ้างอิงขึ้นเอง
   ```

4. เปิดต้นทางตรวจเองอย่างน้อย 2 จุด ไม่ใช้คำตอบที่ Copilot ตรวจตัวเองเป็นหลักฐานเพียงอย่างเดียว
5. ถ้าพบข้อผิดพลาด ให้ส่ง prompt เจาะจงจุดที่พบ โดยแทนข้อความในวงเล็บด้วยรายการที่ต้องตรวจ

   ```text
   ตรวจเฉพาะรายการนี้อีกครั้ง: [รายการที่พบปัญหา]
   ใช้เฉพาะข้อมูลต้นทางที่ให้ไว้
   แสดงค่าที่แก้ไขและหลักฐานที่ตรวจได้ ไม่เกิน 2 bullets
   หากยังไม่มีหลักฐาน ให้ระบุว่ายังยืนยันไม่ได้
   ```

#### Checkpoint

- ตรวจอย่างน้อย 2 จุดกับต้นทางได้ และลบหรือทำเครื่องหมายข้อสรุปที่ยังไม่มีหลักฐาน

## Practice 2: ปรับข้อความให้เหมาะกับหัวหน้าทีม Sales {#practice-2-ปรับข้อความให้เหมาะกับหัวหน้าทีม-sales-10-นาที}

<PracticeIllustration id="verify-02" />

เราจะปรับผลลัพธ์ที่ผ่านการตรวจแล้วให้หัวหน้าทีมอ่านและเห็นงานที่ต้องติดตามได้เร็วขึ้น

#### Steps

1. ใช้ผลลัพธ์ที่ตรวจแล้วจาก Practice 1 เป็นฐาน หาก Chat มีคำตอบเก่าหลายฉบับ ให้คัดลอกเฉพาะฉบับที่ตรวจแล้วกลับมาในข้อความใหม่
2. ส่ง prompt ด้านล่าง โดยไม่เพิ่มข้อมูลหรือไฟล์ชุดใหม่

   ```text
   ใช้เฉพาะผลลัพธ์ที่ตรวจแล้วล่าสุดใน Chat นี้
   ปรับเป็นข้อความภาษาไทยสำหรับหัวหน้าทีม Sales ไม่เกิน 5 bullets
   เรียงเป็น: สถานการณ์สำคัญ สิ่งที่ยืนยันแล้ว ความเสี่ยงที่ต้องตรวจ และ next action
   คงตัวเลขและสถานะเดิม ไม่เติมสาเหตุหรือคำมั่นสัญญา
   ถ้า Owner หรือ Due ยังไม่มีข้อมูล ให้คง [ต้องระบุ]
   ```

3. เทียบข้อความใหม่กับฉบับที่ตรวจแล้ว ดูว่าความหมาย ตัวเลข และข้อมูลที่ยังไม่ยืนยันไม่เปลี่ยน
4. คัดลอกฉบับที่เหมาะสมเก็บไว้เป็นร่าง โดยยังไม่ต้องส่งให้ใครในกิจกรรมนี้

#### Checkpoint

- ข้อความไม่เกิน 5 bullets เหมาะกับหัวหน้าทีม และคงข้อเท็จจริงกับสิ่งที่ยังต้องยืนยันครบ

## Expected Output

- ผลตรวจหลักฐาน 1 ชุด
- ข้อความสำหรับหัวหน้าทีม Sales ที่ปรับแล้ว 1 ฉบับ

เราใช้ AI ช่วยตรวจได้ แต่ยังต้องเป็นคนตัดสินว่าข้อมูลพร้อมใช้หรือไม่
