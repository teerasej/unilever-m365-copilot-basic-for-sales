# Exercise: จัดระเบียบ Launch Action Tracker ด้วย Copilot Pages

[กลับไปหน้า Workshop](../index.md)

## Exercise Overview

เราจะนำ Action Tracker ที่ตรวจแล้วมาเก็บในพื้นที่แก้ไขได้ เพื่อเตรียมใช้ในการประชุมครั้งต่อไป ใช้เวลาประมาณ 8 นาที ส่วนการแชร์เป็นกิจกรรมเพิ่มเติม

> **License:** การใช้ **Copilot Pages**, storage และการแชร์ **ต้องตรวจสอบก่อนเริ่มอบรม** ตามบัญชีและ policy ขององค์กร เส้นทางสำรองใช้ข้อความที่ตรวจแล้วในเอกสาร Word ที่เปิดใช้งานได้ โดยไม่ต้องเพิ่ม Microsoft 365 Copilot add-on license

## Prerequisites

1. ลงชื่อเข้าใช้ [Microsoft 365 Copilot](https://m365copilot.com/) ด้วยบัญชีองค์กร
2. มี Action Tracker ที่ตรวจแล้วจาก [Launch Readiness](copilot-in-action/new-product-launch-readiness.md)
3. หากใช้ Pages ต้องมี storage ที่องค์กรอนุญาต และเห็น **Edit in Pages** ในบัญชี

<span id="practice-1"></span>

## Practice 1: เก็บ Action Tracker เป็น Page (5 นาที)

<PracticeIllustration id="pages-01" />

เราจะเก็บผลลัพธ์ที่ตรวจแล้วเป็น Page โดยคงข้อมูลต้นทางครบถ้วน

#### Steps

1. กลับไปที่คำตอบ Action Tracker ที่ตรวจแล้วใน Chat เดิม ไม่ต้องให้ Copilot สร้างข้อมูลใหม่
2. ถ้าใต้คำตอบมี **Edit in Pages** ให้เลือก แล้วตรวจว่า Page เปิดขึ้น
3. เปลี่ยนชื่อ Page เป็นชื่อด้านล่าง

   ```text
   Sales Launch — Action Tracker
   ```

4. เทียบตารางบน Page กับคำตอบที่ตรวจแล้ว โดยดู Action, Owner, Due และแหล่งข้อมูลอย่างน้อย 1 แถว

> **ถ้าไม่มี Pages:** คัดลอกตารางที่ตรวจแล้วไปยังเอกสาร Word ที่เปิดใช้งานได้ ตั้งชื่อเดียวกัน แล้วทำ Practice 2 ในเอกสารนั้น หากยังเปิดเอกสารไม่ได้ ให้เก็บเป็นข้อความพร้อมคัดลอกไว้ก่อน

#### Checkpoint

- มี Page หรือเอกสารสำรองที่คง Action Tracker เดิม และไม่มี Owner หรือ Due ที่แต่งเพิ่ม

<span id="practice-2"></span>

## Practice 2: เพิ่มจุดที่ต้องยืนยันก่อนประชุม (3 นาที)

<PracticeIllustration id="pages-02" />

เราจะแก้เนื้อหาโดยตรงเพื่อแสดงข้อมูลที่ยังต้องถามต่อให้ชัดเจน

#### Steps

1. เพิ่มหัวข้อด้านล่างท้าย Page หรือเอกสารสำรองด้วยตนเอง

   ```text
   ต้องยืนยันก่อนประชุม
   ```

2. เลือกช่องว่างหรือ `[ต้องระบุ]` จาก Action Tracker 1 จุด แล้วเขียนเป็นคำถาม เช่นใครเป็น Owner หรือกำหนดส่งเมื่อใด โดยยังไม่ใส่คำตอบแทนผู้รับผิดชอบ
3. เปิดอ่านเอกสารอีกครั้ง ตรวจว่าข้อความที่เพิ่มไม่เปลี่ยนสถานะงานเดิม

#### Checkpoint

- มีคำถามที่โยงกับข้อมูลที่ขาด 1 ข้อ และข้อมูลที่ยังไม่ยืนยันยังไม่ถูกแทนด้วยข้อสรุป

<span id="practice-3"></span>

## Practice 3: ตรวจทางเลือกการแชร์ (เพิ่มเติม)

<PracticeIllustration id="pages-03" />

เราจะตรวจผู้รับและสิทธิ์ของ Page ก่อนนำ link ไปใช้ต่อ

#### Steps

1. ถ้าใช้ Pages ให้เปิด **Share** แล้วดูสิทธิ์ที่องค์กรอนุญาต
2. ตรวจว่าผู้รับเป็นผู้ที่ได้รับอนุญาต และเนื้อหาเป็น sample data เท่านั้น
3. หากมี link ที่ใช้ได้ตามสิทธิ์เดิม ให้คัดลอกเก็บไว้ส่วนตัวเพื่อใช้ภายหลัง โดยยังไม่ต้องส่งหรือเชิญคนเพิ่มในกิจกรรมนี้
4. ถ้า policy ไม่อนุญาตหรือไม่แน่ใจ ให้ปิดหน้าต่างแชร์และเก็บ Page ส่วนตัว

#### Checkpoint

- อธิบายได้ว่าใครควรเข้าถึง Page และหยุดก่อนแชร์เมื่อสิทธิ์ยังไม่ชัดเจน

## Expected Output

- Action Tracker บน Page หรือเอกสารสำรอง 1 ชุด พร้อมคำถามที่ต้องยืนยันก่อนประชุม

เรามีทั้ง prompt สำหรับใช้ซ้ำและผลลัพธ์ที่พร้อมหยิบกลับมาใช้แล้ว เลือกงานจริง 1 งานที่อยากทดลองต่อในสัปดาห์นี้นะครับ
